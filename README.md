# MARS — Multi-Platform Music Aggregator

**Версия:** 1.1  
**Статус:** MVP — В разработке  
**Стиль:** Dark / Premium  
**Целевые платформы:** Desktop, Mobile, PWA (Next.js, Tailwind CSS, shadcn/ui)

---

## 🎧 О проекте

**MARS** — персональная музыкальная платформа, объединяющая поиск, музыкальные каталоги и доступные способы воспроизведения нескольких стриминговых сервисов в одном эстетичном интерфейсе.

### Главный принцип
> **Одна композиция — множество источников.**  
> Пользователь видит объединённую карточку трека и самостоятельно выбирает, откуда слушать музыку в зависимости от доступности, качества и предпочтений.

---

## 🛠 Технологический стек

- **Фронтенд & Бэкенд:** Next.js (App Router), React, TypeScript
- **Стилизация & UI:** Tailwind CSS, shadcn/ui, Lucide Icons (Dark / Premium aesthetic)
- **База данных & ORM:** PostgreSQL, Prisma ORM
- **Аутентификация:** Auth.js (NextAuth)
- **Контейнеризация & Деплой:** Docker, Docker Compose, GitHub Actions, VPS
- **PWA:** Поддержка мобильных устройств и десктопа через Web App Manifest и Service Workers

---

## 🎵 Музыкальные интеграции

### Приоритетные (MVP):
1. **Jamendo** — официальный Jamendo API, лицензионная музыка, прямое воспроизведение аудиопотока.
2. **SoundCloud** — официальный виджет / API для поиска, метаданных и воспроизведения.

### Следующие этапы:
3. **Apple Music** — воспроизведение через MusicKit JS.
4. **YouTube** — Data API v3 и официальный встроенный IFrame плеер.

### Исследовательские (вне базового MVP):
- **Spotify** (метаданные и глубокие ссылки согласно Developer Policy)
- **Яндекс Музыка** (исследование API и интеграций)
- **YouTube Music**
- **iCloud Music Library**
