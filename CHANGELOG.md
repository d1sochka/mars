# 📝 Журнал изменений (CHANGELOG) — MARS Music

Все значимые изменения в проекте MARS фиксируются в этом документе.

---

## [v1.2.0] — 2026-11-14

### 🚀 Главные исправления и новые функции
- **Устранение 30-секундного ограничения воспроизведения**:
  - Полностью исключены ознакомительные превью-фрагменты (`previewUrl`).
  - Стандартным и единственным режимом стало **полное воспроизведение композиции от начала до конца (3–5+ минут)**.
  - Интегрирован движок непрерывного воспроизведения `videoResolver.ts` со стабильным стримингом аудио и видеодорожек.
- **Исправление работы музыкальных клипов**:
  - Устранена ошибка воспроизведения видеоклипов (`listType=search unavailable`).
  - Подключены проверенные Video ID для официальных клипов музыкантов (Queen, Brambles, Miyagi, The Weeknd, Billie Eilish, Король и Шут, Daft Punk и др.).
  - В развернутом плеере «Now Playing» переключатель `[🎵 Обложка 328k] / [🎬 Клип / Видео]` воспроизводит клип прямо в карточке трека без прерываний звука.
- **Новая вкладка «Настройки приложения» (Settings)**:
  - Добавлена 5-я вкладка в нижней навигационной панели.
  - **Переключение темы оформления**:
    - ☀️ **Светлая**: мягкий неоморфизм Soft-UI (`#F2F4F8`).
    - 🌙 **Обсидиан**: премиальная глубокая тёмная тема (`#0E1015` / `#16181F`).
    - 💻 **Системная**: автоматическая адаптация под тему ОС.
    - Выбор темы сохраняется в `localStorage` и мгновенно применяется ко всему приложению.
  - Информация о качестве аудио (**328 kbps Hi-Fi Master**), статусе подключенных сервисов и версии приложения.
- **Очистка репозитория**:
  - Удалён неиспользуемый компонент `Sidebar.tsx`.
  - Удалены временные тестовые скрипты (`scratch/`).
  - Файлы дистрибутивов (`dist/`, `*.exe`) исключены из git-индекса в `.gitignore` для оптимизации скорости клонирования и синхронизации. Дистрибутивы распространяются через GitHub Releases.

## [v1.1.0] — 2026-11-14

### ✨ Возможности:
- **Полный редизайн по референсу пользователя**:
  - Неоморфный Soft-UI интерфейс в палитре `#F2F4F8`.
  - Черный парящий мини-плеер Obsidian (`#121316`).
  - Контрастные кнопки `▶ Play` и `🔀 Shuffle`.
  - Разворачиваемый экран «Now Playing» со звуковой волной (waveform visualizer) и таймкодами.
- **Карточки исполнителей**:
  - Горизонтальная карусель популярных артистов на главной странице.
  - Модальное окно артиста (`ArtistModal`) с жанром, слушателями за месяц, кнопками «Слушать всё» и «Перемешать».
- **Избранное (Favorites)**:
  - Добавление любого трека в избранное по клику на сердечко.
  - Вкладка «Медиатека» (Library) с синхронизацией.
- **Автономное приложение Windows**:
  - Упаковка с рантаймом Electron и запуск в отдельном нативном окне Windows (не в браузере).
  - Сборка инсталлятора `MARS_Setup_v1.1.0.exe` через Inno Setup.

## [v1.0.0] — 2026-11-14

### 🎵 Начальный релиз (MVP):
- Архитектура агрегатора потоковой музыки на Next.js, React, TypeScript и Tailwind CSS.
- База данных PostgreSQL / SQLite с Prisma ORM.
- Интеграция Jamendo, Apple Music, YouTube Data API.
- Единый глобальный поиск по 100+ миллионам треков.
- Авторизация пользователей по Email и номеру телефона.
